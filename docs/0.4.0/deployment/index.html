From local to live.

This part of Caramel’s story is still being built. A production guide will need a maintained example and a verified deployment lifecycle.

Not yet supported as a complete workflow0.4.0 baseline

What works locally

Latte manages local services and named HTTPS; Frappé builds and supervises your development app. These capabilities do not establish a production deployment path.

What must be verified before launch

  • Build and run the target artifact Open
  • Configure secrets and PostgreSQL Open
  • Apply migrations and serve assets Open
  • Run workers and check health Open
  • Drain work during shutdown Open
  • Recover or roll back a release Open
A clear promise

The website should publish a deployment recipe only after that exact release and target environment pass these checks.
