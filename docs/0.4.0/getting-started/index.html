Learn / The Bookshelf path

Start with something real.

A small application, built one understandable step at a time. Start with setup, then follow the same feature through your application.

Before you start

The current source installation targets Apple Silicon macOS with Apple Command Line Tools. The full setup guide is linked below; these commands assume Frappé, Latte, and local HTTPS are already configured.

01 · Set up your environment

Install one release and use its matching documentation. This preview targets 0.4.0. The repository README currently starts at 0.1.0; that version mismatch needs correcting before this learning path launches.

Review current installation instructions ↗

02 · Create your bookshelf

Terminal · after completing machine setup
frappe new bookshelf
cd bookshelf
frappe make resource Book title:string author:string
frappe migrate
frappe dev

The generated files are yours to edit. Begin with the route, action, model, and view for Books.

03 · Check your first feature

Terminal · inside bookshelf
frappe routes books
frappe check
frappe corretto

Expect book routes, a successful type check, and passing generated request specs. Run these checks in your application; the examples are not yet recipe-tested.
