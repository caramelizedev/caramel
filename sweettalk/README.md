# SweetTalk

SweetTalk is a language for Domain-Driven Design in applications built with
[Caramel](https://github.com/caramelizedev/caramel): contexts, values, aggregates, events,
policies, projections and processes, each a word that the compiler checks.

This shard is written in Caramel's repository, in its `sweettalk/` directory. It shares
Caramel's version number, and each release depends on the Caramel release of that number.

- Read the guide at https://caramelize.dev/docs/: it shows how an application adds the
  shard and what each word does.
- Report a problem or contribute at https://github.com/caramelizedev/caramel.
